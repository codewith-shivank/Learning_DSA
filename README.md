# DSA Java Learning Workspace

A structured Java and DSA learning workspace.

## Folders

- `01-Java-Basics` — Java language fundamentals, variables, data types, and operators.
- `02-Flowcharts-and-Pseudocode` — Problem-solving exercises with Java solutions, flowcharts, and pseudocode.
- `03-Live-Sessions` — Code written during live learning sessions.

## Recommended progression

1. Variables and data types
2. Arithmetic and type casting
3. Flowcharts and pseudocode
4. Live practice sessions
5. Data structures and algorithms
