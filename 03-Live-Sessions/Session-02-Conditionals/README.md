# Session 02: Conditionals

[All sessions](../README.md)

| Program | What it demonstrates | Input |
| --- | --- | --- |
| [FeverCheck.java](./FeverCheck.java) | An `if/else` temperature check using a threshold of `100`. | One integer temperature, such as `101`. |
| [LeapYear.java](./LeapYear.java) | Divisibility checks for leap years, including century years. | One integer year, such as `2024`. |

Compile using the [root instructions](../../README.md#compile-all-programs), then run from the repository root:

```sh
java -cp build/classes LeapYear
```

Try `2024`, `1900`, and `2000` in separate runs to explore the leap-year conditions.
